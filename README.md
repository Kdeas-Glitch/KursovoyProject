## 🛠 Технологический стек

Пока нечего сюда кидать

| Компонент | Выбранная технология | Альтернативы | Основные преимущества выбора |
| :--- | :--- | :--- | :--- |
| **Язык разработки** | **C# (.NET)** | Python, Java | Готовая экосистема (`VkNet`), высокая производительность, строгая типизация. |
| **Backend API** | **ASP.NET Core Web API** | FastAPI, Express.js | Многопоточность, высокая пропускная способность под нагрузкой, удобная интеграция с БД через EF Core. |
| **Frontend** | **Blazor** | Trad. MPA, JS-фреймворки | Единый язык разработки (C#), быстрая инициализация, богатый набор готовых UI-компонентов. |
| **База данных** | **PostgreSQL** | MySQL | Нативная и эффективная работа с JSON/JSONB, высокая отказоустойчивость (ACID). |
